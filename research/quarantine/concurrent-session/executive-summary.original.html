5 Steps to Submit

  1. Go to DOE GEMS Prize competition page and log in.
  2. Click "Submit" or go to submission page. Read submission format: single-band GeoTIFF, float32, EPSG:32611, 100m, same bounds, values in [0,1].
  3. In "File to submit" choose the downloaded .tif or .zip (single GeoTIFF inside). Our file is validated: single-band float32, EPSG:32611, 3730×3292, transform [100,0,243350,0,-100,4508550], min 0.0 max 1.0, 0 NaN inside footprint for all-finite version, 37654 dots.
  4. In "Note (optional)" paste: GEMSDOE83 P5-Q basement triple: depth+grav slope+mag vert grad, 37654 binary off-cat dots, piedmont blind, 300m submodular
  5. Click Create submission. If you get error "Predicted values must be in range [0,1]", use the all-finite version (nodata=None) — it is fixed. If you used NaN version, try all-finite.
