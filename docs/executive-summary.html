What will be required before a file is enabled

  1. The session’s assigned method paragraph and canonical template/tool paths are recorded.
  2. The candidate is built from the authorized feature stack using the shared evaluator/writer, and every catalogue-derived feature is fold-local.
  3. Each feature passes its holdout leakage canary; the whole-segment buffered holdout reports evaluator version, withheld positives, pooled HOLDOUT-DTI, and 95% CI.
  4. The surface is compared with every registry raster before placement, and the final dots are checked against every registry raster. A threshold breach is logged as a duplicate and stops publication.
  5. The final bytes are reopened and machine-validated: one band; no NaN in the footprint; values in [0,1]; exact CRS, shape, and geotransform; unique filename; SHA-256 receipt.
  6. The current run card says `submission_ready: true`. Only then will this page show the one file link, unique submission name, and note of no more than 140 characters.

Portal steps after the site says READY

  1. Open the official DOE GEMS Prize page and sign in through the organizer’s normal flow.
  2. Download only the GeoTIFF linked from the READY project landing page. Confirm the displayed filename and SHA-256 match the run card.
  3. On the competition submission form, select the downloaded single-band GeoTIFF. The user-supplied form text says a single-band GeoTIFF or ZIP containing a single GeoTIFF is accepted; verify the current form before upload because the page was not fetched in this session.
  4. Copy the unique name and short note exactly from the run card into the corresponding submission fields.
  5. Submit, save the organizer’s submission-page receipt, and only then record its score as ORGANIZER-CONFIRMED. This project does not choose a weekly slot or submit automatically.
